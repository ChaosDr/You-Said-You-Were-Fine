# You Said You Were Fine

Latest game export, version 8.

## Publish on GitHub Pages

1. Extract this ZIP.
2. Open your GitHub repository and choose **Add file → Upload files**.
3. Upload **all the extracted files together** to the repository root. `index.html` must be directly at the top level. Do not upload the ZIP itself or the enclosing download folder.
4. Open **Settings → Pages**.
5. Choose **Deploy from a branch**, select **main** and **/ (root)**, then **Save**.
6. Wait for GitHub Pages to finish deploying, then open the site URL shown there.

To update an existing game, replace the root files with these files. Keep all filenames unchanged. A project page such as `https://username.github.io/repository/` is supported; every game reference is relative.

## Test on your computer

Open `index.html`. Images and sprite data are included locally. No installation, build command, external service, or internet connection is required to play.

## Controls

Arrow keys / WASD: walk. E / Space: interact. Click or tap an object or its small ! marker to walk to it. The on-screen directional pad supports phones. Menu pauses the evening. During the keys task, avoid guests’ pale sightlines or wait for them to turn.

All game files are in this one directory; there are no assets or vendor subfolders.
